## Enunciado
Desarrolla un programa en Python que solicite dos números decimales y muestre el resultado de las cuatro operaciones aritméticas básicas: suma, resta, multiplicación y división.

---

## Implementa las siguientes funciones:

<span style="color: red;">sumar(numero1, numero2)</span>: devuelve la suma de los dos números.

<span style="color: red;">restar(numero1, numero2)</span>: devuelve la diferencia entre ambos números.

<span style="color: red;">multiplicar(numero1, numero2)</span>: devuelve el producto de ambos números.

<span style="color: red;">dividir(numero1, numero2)</span>: devuelve el cociente de ambos números.

Antes de realizar la división, comprueba que el divisor sea distinto de cero. Si es cero, muestra un mensaje indicando que no se puede realizar la operación.

---

## Ejemplo de ejecución<br>
10<br>
4<br>
Suma: 14.0<br>
Resta: 6.0<br>
Multiplicación: 40.0<br>
División: 2.5<br>
